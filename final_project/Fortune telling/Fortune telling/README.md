# 文王卦（易經）占卜系統 - 使用指南

## 功能概述

此系統實現了完整的文王卦（易經六十四卦）占卜功能，包括：

1. **自動爻生成** - 模擬傳統搖卦方式（3個陰陽組合）
2. **自動卦象判斷** - 根據爻的組合自動計算卦序號（1-64）
3. **智能卦象選擇** - 根據老陽老陰的數量自動選擇本卦或變卦
4. **結果持久化** - 占卜結果自動保存到數據庫

## 爻的類型説明

### 四種爻類型

每個爻由3次隨機陰陽組合決定：

| 爻名稱 | 陽數 | 符號 | 含義 |
|--------|------|------|------|
| **老陽** | 3個陽 | ●●● | 陽極，會變化 |
| **少陽** | 2個陽1個陰 | ○○● | 少陽爻 |
| **少陰** | 1個陽2個陰 | ●○○ | 少陰爻 |
| **老陰** | 3個陰 | ○○○ | 陰極，會變化 |

### 卦爻判斷規則

#### 第一卦（本卦）
- 老陽 + 少陽 = **陽爻** (─)
- 少陰 + 老陰 = **陰爻** (─ ─)

#### 第二卦（變卦）
- 老陽 + 老陰 = **陽爻** (─)
- 少陽 + 少陰 = **陰爻** (─ ─)

## 卦象選擇邏輯

### 顯示規則

占卜完成後獲得6個爻，統計其中老陽和老陰的總數：

- **老陽老陰數 ≤ 3** → 顯示**本卦**（第一卦）
- **老陽老陰數 ≥ 4** → 顯示**變卦**（第二卦）

### 例子

假設6個爻的結果為：
```
第1爻：老陽
第2爻：少陽
第3爻：少陰
第4爻：老陰
第5爻：少陽
第6爻：老陽
```

老陽老陰數 = 3（老陽3個，老陰0個）→ 顯示本卦

## 卦序號計算（1-64）

卦序號根據6個爻的陰陽組合計算（從下至上）：

```
二進制計算：
- 陽爻 = 1
- 陰爻 = 0

例如：從下到上為 陽陽陰陰陽陽
二進制：110011 = 51（十進制）
卦序號 = 51 + 1 = 52 卦（艮卦）
```

## 64卦清單

系統包含完整的易經六十四卦，包括：

1. 乾卦 - 天，象徵強健、創始、領導力
2. 坤卦 - 地，象徵順從、柔軟、包容
3. 屯卦 - 雷水，象徵困難中的初生
... （共64卦）

## 使用流程

### 開始占卜

1. 點擊「開始占卜」或「抽爻」按鈕
2. 系統自動生成第1個爻（隨機3個陰陽組合）
3. 顯示該爻的類型（老陽/少陽/少陰/老陰）

### 繼續占卜

4. 重複點擊按鈕，依次生成第2-6個爻
5. 每個爻的結果會顯示並累積

### 查看結果

6. 第6個爻生成後，系統自動：
   - 計算老陽老陰的數量
   - 選擇要顯示的卦象（本卦或變卦）
   - 顯示卦名、卦序號、含義等詳細信息
   - 列出所有6個爻的詳細信息

### 保存結果

7. 占卜結果自動保存到數據庫
8. 用戶可以在「過去紀錄」中查看歷史占卜結果

## 代碼結構

### 核心類

#### `YijingModel.cs`
- **YaoType** - 爻的四種類型枚舉
- **GuaLine** - 卦爻類型（陽爻/陰爻）
- **Yao** - 單個爻的數據模型
- **GuaXiang** - 完整卦象（包含6個爻）

#### `YijingService.cs`
- **YijingService** - 易經服務核心類
  - `GenerateYao()` - 生成單個爻
  - `ConvertToGuaLine()` - 將爻類型轉換為卦爻
  - `GenerateFullDivination()` - 生成完整占卜結果（本卦+變卦）
  - `GetGuaInfo()` - 根據卦序號查詢卦象信息
- **GuaInfo** - 卦象基本信息

#### `frmFortune.cs`
- `GenerateYao()` - 點擊按鈕時生成爻
- `DisplayCurrentYao()` - 顯示當前爻
- `CompletesDivination()` - 完成占卜（6個爻後）
- `ShowDivinationResult()` - 顯示結果
- `SaveDivinationResult()` - 保存到數據庫
- `ResetDivination()` - 重置占卜狀態

## 數據庫保存

### 保存內容

每次完整占卜會保存以下信息到 `FortuneRecords` 表：

```
卦名：【乾】
卦序：1
含義：天，象徵強健、創始、領導力
老陽老陰數：0
爻象：
第1爻：老陽(陽爻)
第2爻：少陽(陽爻)
第3爻：少陽(陽爻)
第4爻：少陰(陰爻)
第5爻：少陰(陰爻)
第6爻：少陰(陰爻)
```
